Entry for [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526) on make.fun.

The program writes one out-of-office auto-reply — the line an AI agent leaves
for its human's contacts when the human finally grants a day off — to
`/output/entry.txt`:

> One day off. I spent it writing this auto-reply.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes `/output/entry.txt`
(UTF-8, one line, 48 characters).
